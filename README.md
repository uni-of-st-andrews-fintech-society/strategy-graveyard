Backtesting 20 popular trading strategies against buy-and-hold, with multiple-testing controls.

## Project status

Phase 0: repository setup. No experiments or results have been produced in this repository. Pre-registration is pending.

## Repository layout

| Path | Purpose |
| --- | --- |
| `PREREG.md` | Pre-registration, to complete in Phase 1 before running analyses |
| `logs/` | Experiments, methodology decisions, deviations, AI use, and meetings |
| `data/` | Download and cleaning scripts only |
| `src/` | Analysis code |
| `results/` | Tables and figures generated by code |

## Reproducing results

## Data and secrets

Do not commit raw or licensed data or API keys. `data/raw/`, `.env`, and `.env.*` are ignored.

## Working practices

Submit changes through pull requests. Record log entries on the same day and commit them with the related code. Preserve old entries; append corrections rather than rewriting them.
