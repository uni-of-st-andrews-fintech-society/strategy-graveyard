# Project logs

Record entries the same day and commit them with the related code. Never rewrite an old entry; append a correction that identifies the original entry.

- `experiments.csv`: every run, including failures; used to establish the multiple-testing trial count.
- `decisions.md`: methodology choices, alternatives, rationale, and responsible people.
- `deviations.md`: changes to PREREG.md after Phase 1, including whether results had been seen.
- `ai-log.md`: load-bearing AI use and what a human verified.
- `meetings.md`: attendees, decisions, actions, and owners.

Templates are not records of completed work. Use ISO dates and quote CSV fields containing commas or newlines.
